# stetho-lab

> 🚧 **Not ready yet — still in the making. Stay tuned!**

The public lab of **Fenstra Stetho**, a specialized PC service toolkit. Stetho scans a PC, scores its health, and predicts how much better it can get: faster boot, more free space, better security.

The full Stetho platform also uses a specially trained AI model and can automate the fixes. Those parts run on Fenstra servers and are not included here. Access is available on request.

**Free to explore and experiment with for personal, non-commercial use.** Have a great improvement? Open a pull request. Good contributions get merged and rewarded.
